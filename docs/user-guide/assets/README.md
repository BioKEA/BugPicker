# User Guide Images

Place screenshots or photographs here with the filenames below, then run:

```bash
python3 docs/user-guide/build_user_guide.py
```

The guide builds without them and displays labeled placeholders. Remove sensitive collection identifiers before taking screenshots. Keep these filenames when replacing outdated images so the guide source does not need to change.

| Filename | Capture |
|---|---|
| `machine-overview.jpg` | Entire machine with sorting trays, plate, recovery plate, N1, and cameras identifiable. |
| `emergency-controls.jpg` | Machine power and emergency controls. |
| `openpnp-home.png` | OpenPnP after successful startup and homing. |
| `scripts-menu.png` | `BugPicker > 00_Run_BugPicker` submenu. |
| `run-layout.png` | Main run-layout window with representative metadata. |
| `calibration-window.png` | Tray, HiRes A1, plate, and recovery calibration controls. |
| `tray-loaded.jpg` | Correctly seated automation tray with separated specimens. |
| `scan-review.png` | Target review with included and excluded targets. |
| `plate-review.png` | Completed-run plate map/review. |
| `manual-imaging.png` | Manual imaging setup and HiRes-over-A1 calibration. |
| `taxonomy-review.png` | Taxonomy review, consistency choices, and notes. |
| `qa-label-review.png` | QA label review with available labels. |
| `model-report.png` | Candidate report and promotion recommendation. |
